# MAKA logo package

Color-layer vector trace based on the supplied gym logo. The red and white silhouettes, yin-yang construction and brush texture are preserved from the original artwork. Compact application headers use the same detailed master instead of a separate reinterpretation.

## Files

- `maka-mark.svg`: primary symbol for light backgrounds.
- `maka-mark-inverse.svg`: symbol for dark backgrounds.
- `maka-lockup-horizontal.svg`: horizontal lockup for light backgrounds.
- `maka-lockup-horizontal-inverse.svg`: horizontal lockup for dark backgrounds.
- `maka-lockup-stacked.svg`: complete stacked signature on an ink background.
- `maka-monochrome.svg`: single-color mark.
- `maka-favicon.svg`: compact app/browser icon.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| MAKA Red | `#EF252C` | Brand accent, active states, highlights |
| MAKA Red Dark | `#B5121B` | Text accent on light backgrounds, borders |
| Ink | `#0B0B0D` | Primary text and dark backgrounds |
| Carbon | `#18181B` | Dark surfaces and controls |
| Warm White | `#F7F6F3` | Light text and surfaces |
| Silver | `#B8B8BD` | Secondary text on dark backgrounds |
| Mist | `#EEECEA` | Light page background and separators |

The interface uses black text on MAKA Red for normal-size action labels; this has stronger contrast than white on the bright source red.

## Clear space

Keep clear space around each signature equal to at least one quarter of the mark diameter. Do not recolor individual figures, stretch the artwork, add shadows, or place the inverse version on a light surface.
